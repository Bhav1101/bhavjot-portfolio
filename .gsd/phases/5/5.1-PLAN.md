# Plan 5.1: Implement Contact Form Component

## Objective
Implement the contact form functionality on the frontend, allowing users to submit messages that are sent to the backend `/api/contact` endpoint, and integrate the component into the main single-page layout.

## Context
Load these files for context:
- .gsd/SPEC.md
- client/src/App.jsx

## Tasks

<task type="auto">
  <name>Create Contact Section Component</name>
  <files>
    client/src/components/sections/Contact.jsx
  </files>
  <action>
    Create the Contact form component as specified in the SPEC.
    
    Steps:
    1. Create `client/src/components/sections/Contact.jsx`.
    2. Build a form with Name, Email, Budget dropdown, and Message fields, and a Submit button.
    3. Use standard React state (`useState`) to manage form inputs and submission state (loading, success, error).
    4. Implement the submission handler to send a `POST` request to `http://localhost:3000/api/contact` with the form data.
    5. Handle loading states and display success/error feedback messages appropriately.

    USE: Tailwind CSS for clean, consistent styling.
  </action>
