# Project Roadmap

## Phase 1: Scaffolding
- Initialize `client/` React app (Vite + Tailwind + Framer Motion).
- Initialize `server/` Node app (Express + Mongoose).
- Setup ESLint/Prettier (if applicable).
- Set up project structure and environment variables.

## Phase 2: Backend/API
- Model MongoDB collection: `ContactMessage`.
- Build REST endpoint for contact form.
- Add Nodemailer logic for the contact endpoint.

## Phase 3: Frontend Scaffolding & Design System
- Setup the design system (ui-ux-pro-max recommendations).
- Define global styles, color palette, and typography.
- Setup base layout and hardcode CV data in a central configuration file.

## Phase 4: Frontend Sections (CV Order)
- Hero & Stats components.
- Skills, Experience, and Projects components.
- Certifications, Education components.
- Render components using the hardcoded CV data.

## Phase 5: Styling Pass & Contact Form
- Polish styling to match reference site visual components (framer-motion animations).
- Implement Contact form functionality and email dispatch.
- Final visual verification.

## Phase 6: Deploy Prep
- Add build scripts and setup environment configurations for production.
- Final verifications.
